# Iris Flower Classification

## Project Overview

This project is about using Machine Learning to figure out what kind of Iris flower we are looking at. We want to know if it is an Iris Setosa, an Iris Versicolor or an Iris Virginica. The Iris Flower Classification project is about Iris flowers. We are trying to find out what kind of Iris flower we have.

The Iris Flower Classification model looks at four things about the Iris flower to make a prediction:

* The length of the sepal of the Iris flower

* The width of the sepal of the Iris flower

* The length of the petal of the Iris flower

* The width of the petal of the Iris flower

## Dataset

We used a known set of data about Iris flowers for the Iris Flower Classification project. This set of data has a lot of information about the Iris flowers. What kind of Iris flowers they are.

## Project Workflow

Here is what we did for the Iris Flower Classification project:

1. We looked at the data for the Iris Flower Classification project. We got to know the data.

2. We cleaned up the data for the Iris Flower Classification project so it was good to use.

3. We split the data for the Iris Flower Classification project into two groups: one to train the Iris Flower Classification model and one to test it.

4. We taught the Machine Learning model for the Iris Flower Classification project what to do.

5. We checked to see how well the Iris Flower Classification model was doing.

6. We used the Iris Flower Classification model to predict what kind of Iris flower we were looking at.
